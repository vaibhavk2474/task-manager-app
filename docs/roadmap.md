# Roadmap

This is a planning guide, not a commitment. Keep each milestone small and based on a user need.

## 1. First release

- Account registration, sign-in, session restore, and sign-out.
- Owner-scoped MongoDB task CRUD.
- Overview and All tasks navigation, with All/today/upcoming/overdue/completed filters, search, priority, optional date/time deadlines, and paginated card/table views.
- Responsive Overview dashboard with today's focus, upcoming tasks, overdue visibility, and completion progress.
- Centralized light/dark theme.

## 2. Everyday planning

- Sorting and bulk task actions.
- Bulk completion and keyboard shortcuts.
- Accessibility review and focused empty/loading/error states.

## 3. Larger features

Recurring tasks, labels, projects, reminders, exports, and collaboration require a specific user story and data/privacy decisions before implementation.
